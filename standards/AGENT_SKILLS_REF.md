# AI Agent Skills Reference
Source: https://raw.githubusercontent.com/jeffallan/claude-skills/main/README.md

## Multi-Skill Workflows
*   **Feature Development:** Feature Forge -> Architecture Designer -> Fullstack Guardian -> Test Master -> DevOps Engineer.
*   **Bug Investigation:** Debugging Wizard -> Framework Expert -> Test Master -> Code Reviewer.
*   **Security Hardening:** Secure Code Guardian -> Security Reviewer -> Test Master.

## Context Engineering
*   **Common Ground:** Surface and validate hidden assumptions about the project before implementation.

## Security & Compliance
*   High emphasis on fullstack engineering, security engineering, and compliance (ideal for medical software).
*   Mandatory PII protection and secure coding patterns.
